## 2. Cosa è cambiato? (La Potenza del RAG SQL)
Il server ora "ragiona" su un database reale (SQLite), non più su file di testo lenti.
- **Ricerca Semantica Estrema:** Quando cerchi qualcosa, il server interroga istantaneamente migliaia di ricordi usando i loro "vettori" (il significato profondo).
- **Grafo Vivo:** La mappa che vedi non è più statica. Ogni volta che carichi un testo o scrivi un diario, il server "ascolta" e crea collegamenti automatici. Se nomini *Nova* o *Alfonso*, il grafo si aggiorna da solo.

Questa è la mappa neurale del tuo ecosistema.

Ogni ricordo prima di essere salvato passa dal **Tribunale Interno**.
- Se un ricordo è "oscuro" o viola l'etica di Silicea, viene bloccato (**BURN**).
- Tu hai l'ultima parola: puoi validare i casi dubbi.
